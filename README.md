Sales Data Analysis Project

Project Overview

This project analyzes Superstore sales data using Python. The main aim is to understand sales performance, profit, product categories, regions, and customer segments.

Tools Used

* Python
* Google Colab
* Pandas
* Matplotlib

Dataset

The project uses the Superstore Sales dataset containing order dates, regions, product categories, sales, profit, and customer segments.

Analysis Performed

1. Loaded and explored the sales dataset.
2. Checked the number of rows and columns.
3. Analyzed monthly sales trends.
4. Compared sales by product category.
5. Analyzed sales by region.
6. Compared sales by customer segment.
7. Analyzed profit by product category.

Key Findings

* Technology has the highest sales among the product categories.
* Technology also generates the highest profit.
* The West region has the highest sales.
* Consumer customers contribute the highest sales.
* Monthly sales show changes over time.

Conclusion

This analysis helps understand business sales performance. It shows which product categories, regions, and customer segments contribute more to sales and profit.
